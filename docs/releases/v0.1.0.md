# Finder Favorites v0.1.0

This is the first source release. It contains no prebuilt or notarized macOS
executable. Build it locally with Xcode or through Nix on Apple silicon.

## Changelog

- Add declarative planning, drift checks, apply, and recovery for Finder
  Favorites.
- Add additive-only reconciliation, a private recovery journal, and a lock
  against concurrent writes.
- Isolate the deprecated macOS sidebar API in a small C bridge and add Swift,
  bridge, sanitizer, and Nix checks.

## Compatibility and support

The supported build target is Apple silicon on macOS 14 or newer. Finder uses a
deprecated API that Apple may remove in a future macOS release. Security reports
for this source release are accepted through 2027-03-24. Fixes may ship in a
newer version; this archive will not be changed. See
[SECURITY.md](../../SECURITY.md) for private reporting.

## Build and verification

Run `swift test` and `swift build -c release` with a supported Xcode toolchain,
or run `nix build .` from the extracted archive on a supported
Mac. The release includes a SHA-256 checksum, a release manifest, and a Sigstore
SLSA provenance bundle for the exact source archive. Follow
[release verification](../security-and-releases.md#verify-a-source-release)
before using the archive. The Nix package remains available through
[`nixpkgs-personal`](https://github.com/nix-forge/nixpkgs-personal).
